# Climate Station System
This project was built as part of the Connectors Training Program (Connectors Team – Faculty of Engineering, Mansoura University).
A simple and affordable Arduino-based Climate Monitoring Station that measures temperature and humidity and displays the data on an Oled Display or through the Serial Monitor.

# 🔹Features
- Temperature Measurement
- Humidity Measurement
- Real-time display using OLED
- Easy-to-build and fully open-source
- Simple, clean, and well-commented Arduino code

# 🔹Components
- Arduino UNO
- Oled Display
- DHT11
- Jumper Wires
- Breadboard

# 🔹Libraries
- DHT11 Sensor Library - https://github.com/adafruit/DHT-sensor-library
- Adafruit_SSD1306 - https://github.com/adafruit/Adafruit_SSD1306
- Adafruit_GFX - https://github.com/adafruit/Adafruit-GFX-Library
